# المتطلبات المرجعية — ملخص PRD و SWET

المصدر: وثيقتا المالك `PRD.pdf` (متطلبات المنتج) و `SWET.pdf` (المواصفات الهندسية)، وبرومبت التصميم المرفق، بتاريخ 2026-10-20.

## الفكرة
منصة تربط أصحاب المطاعم والكافيهات بالمستشارين الخبراء ومقدمي الخدمات، مستلهمة من قنوات الواتساب المتخصصة (قناة وظائف عمال المطاعم، وقناة استشارات المستشار محمد الشحادة).

## الأدوار
| الدور | الصلاحيات |
|---|---|
| CLIENT صاحب مطعم/كافيه | يطلب استشارات، ينشر طلبات موظفين/معدات/منتجات |
| CONSULTANT مستشار | يستقبل الحجوزات، يدير مواعيده — يظهر للعموم بعد اعتماد المدير (`is_verified`) |
| VENDOR مورد/باحث عمل | يعرض معدات ومنتجات، يتقدم للوظائف |
| ADMIN مدير | اعتماد المستشارين، مراقبة المحتوى — لا يُسجَّل ذاتياً |

## الأقسام
1. **الاستشارات المباشرة:** حجز من جدول مواعيد، قنوات تواصل (نص/صوت/فيديو)، أرشفة الجلسات.
2. **سوق الطلبات:** JOBS · EQUIPMENT · SUPPLIES · SERVICES، مع `metadata` JSONB لكل قسم.
3. **التكامل الاجتماعي:** نشر تلقائي على X و Facebook و TikTok و Snapchat، وتسجيل دخول اجتماعي.

## خطة المراحل (PRD)
1. MVP: الهيكل، القاعدة، التسجيل، أقسام الطلبات.
2. حجز الاستشارات وإدارة الجداول.
3. ربط APIs منصات التواصل.
4. إطلاق تجريبي واختبار أداء وأمان.

## ما نُفّذ في الجولة الأولى (2026-10-20) بقرار المالك
النطاق: **الأساس + السوق + الاستشارات** (المرحلتان 1 و2، وهيكل المرحلة 3).

## قرارات وانحرافات موثقة عن الوثائق
| البند | الوثيقة | المنفّذ | السبب |
|---|---|---|---|
| Redis/BullMQ | إلزامي | اختياري؛ fallback داخل العملية | قرار المالك — لا Redis على جهاز التطوير |
| حالة سجل النشر | SUCCESS/FAILED | + SKIPPED | منصة بلا مفاتيح ليست فشلاً |
| ردّ الحجز | 200 OK | 200 OK (مطابق) | — |
| رابط الجلسة | `/meet/{8 أحرف}` | `/meet/{UUID كامل}` | منع التخمين والتصادم |
| JWT | Bearer | Bearer + كوكي httpOnly | صفحات EJS تحتاج جلسة بالمتصفح |
| bcrypt cost | ≥ 12 | 12 (قابل للرفع حتى 15) | مطابق |
| الجداول | SQL مباشر | Sequelize `sync()` (إنشاء فقط) | MVP؛ الهجرات (migrations) مطلوبة قبل الإنتاج |
| مكالمات صوت/فيديو | مدمجة | غرفة جلسة بالتفاصيل والعد التنازلي، بلا فيديو بعد | تحتاج مزوّد WebRTC — قرار للمالك |
| TikTok/Snapchat | نشر | مُسجَّل FAILED بسبب واضح | تتطلب توليد بطاقات/فيديو (مرحلة لاحقة) |
| رفع الصور | — | روابط صور فقط | تخزين الملفات قرار مؤجل (S3/R2/محلي) |
